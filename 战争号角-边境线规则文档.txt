# 《战争号角-边境线》规则书 v6.2

**类型**：双人回合制战略棋类  
**时长**：线上30-60分钟


## 第一部分：核心规则


### 第一章：棋盘与兵力

#### 1.1 棋盘

- 19路棋盘（19×19，361个交叉点）。
- **第10行 = 边境线**，不归属任何一方。
- **第1-9行 = 黑方领土**，边界包括上边界及左右边界第1-9行段。
- **第11-19行 = 白方领土**，边界包括下边界及左右边界第11-19行段。

#### 1.2 兵力

- 双方各有兵力上限（默认120子，可配置），不可再生。
- 一方用尽后无法落子，双方均无法落子时强制终局。


### 第二章：得分总则

**总分 = 占领分 + 防御分 - 战损分**

所有分数均为盘中实时动态计算。

| 分数类型 | 构成 | 说明 |
|---|---|---|
| **占领分** | 活子分 + 围空分 | 在对方领土上的控制力 |
| **防御分** | 歼灭分 + 围困分 | 在己方领土上的防守战果 |
| **战损分** | — | 被提吃的代价 |

#### 2.1 贴目规则

**白方获得+0.5分贴目补偿。**

- 终局结算时，白方总分额外+0.5分。
- 由于所有分数均为整数，这等价于：**双方总分相等时，白方获胜**。
- 贴目仅用于终局胜负判定，不影响盘中计分显示。


### 第三章：占领分

**占领分 = 活子分 + 围空分**

#### 3.1 活子分

**定义**：在**对方领土**或**边境线**落子，落子后有气，该子立即获得+1活子分。无上限。

| 触发 | 变化 |
|---|---|
| 落子**对方领土**或**边境线**，落子后有气 | +1/子 |
| 被提吃（任何情况） | -1/子 |
| 被判定为围困 | -1/子 |
| 围困解除（做活/突破/空点恢复） | +1/子 |

**有气**：棋子所在连通块存在至少一个相邻空交叉点。

#### 3.2 围空分

围空分的完整规则见**第四章：包围圈与围空**。


### 第四章：包围圈与围空

#### 4.1 包围圈的定义与判定

**包围圈**：由一方棋子在棋盘上形成的完全封闭的几何边界。

**构成要素**：
- **围棋子**：己方棋子，彼此通过上、下、左、右相邻关系直接或间接连接，形成连续的墙。
- **棋盘边界**：四条边缘作为天然围墙参与包围，但需用棋子占据参与包围的边界的**两个端点**。
- **封闭性**：边界首尾相连，无缺口。

**判定**：纯几何判定。从圈外任意一点出发，必须穿过包围方棋子链或棋盘边界才能到达圈内。

**边界棋子不纯**：双方棋子共同围成的封闭区域不认定为任何一方的包围圈。

**有效包围圈**：由**活棋**围成的包围圈。由围困棋子围成的包围圈无效。

#### 4.2 围空分的计算

**基本计算**：在对方领土或边境线形成有效包围圈，圈内每个交叉点+2分。

**扣除对方活棋**：圈内对方活棋占据的交叉点，不计入围空分。

**对方围困棋子**：圈内对方围困棋子占据的交叉点，计入包围方围空分（被俘获）。

**己方棋子**：圈内己方棋子（无论死活）占据的交叉点，不影响围空分计算。

**有效围空点数 = 圈内总交叉点数 - 圈内对方活棋占据的点数**

**动态更新**：包围圈形成/扩大/缩小/被突破时实时加减分。

#### 4.3 嵌套包围圈

从内向外逐层判定：
- 内层由**活棋**围成 → 内层区域归内层方，外层有效围空点数扣除内层全部区域。
- 内层由**围困**围成 → 内层无效，区域归外层有效包围方。

动态更新：内层棋子死活状态变化时，立即重新判定嵌套归属并更新双方围空分。

#### 4.4 圈内棋子状态转换的分数变化

**一、进攻方棋子状态转换（进攻方棋子在防守方包围圈内）**

| 转换方向 | 触发条件 | 防守方围困分 | 进攻方活子分 | 围空分 |
|---|---|---|---|---|
| 活→围 | 被有效包围+无两眼+空点<4 | +1/子 | -1/子 | 该子所在点开始计入防守方围空分 |
| 围→活(做活) | 做出两眼 | -1/子 | +1/子 | 该子所在点不再计入防守方围空分 |
| 围→被吃 | 被提吃 | -1/子 | — | 歼灭+2；战损-1 |
| 围→突破 | 包围圈被破坏 | -1/子 | +1/子 | 防守方包围圈消失，围空分全扣 |
| 围→空点恢复 | 空点恢复到≥4 | -1/子 | +1/子 | 该子所在点不再计入防守方围空分 |

**二、防守方围成棋子的状态转换**

| 转换方向 | 触发条件 | 进攻方围困分 | 防守方活子分 | 围空分 |
|---|---|---|---|---|
| 活→围 | 被有效反包围+满足围困条件 | +1/子(若适用) | -1/子(若适用) | 防守方该包围圈围空分扣除 |
| 围→活 | 解除围困 | -1/子 | +1/子(若适用) | 防守方该包围圈围空分恢复 |

**嵌套更新**：防守方围成棋子状态变化时，其包围圈内的区域归属立即重新判定。

#### 4.5 边境线特殊规则

边境线（第10行）不归属任何一方。双方均可在此获得占领分和防御分。边境线上的包围圈，圈内空地+2占领分，圈内对方困子+1防御分，两者可叠加。


### 第五章：防御分

**防御分 = 歼灭分 + 围困分**

#### 5.1 歼灭分

| 触发 | 变化 |
|---|---|
| 在**己方领土**提吃对方棋子 | +2/子 |
| 在**边境线**提吃对方棋子 | +2/子 |
| 在**对方领土**提吃对方棋子 | **不计歼灭分** |

**说明**：歼灭分衡量防守战果，仅在己方地盘或边境线消灭敌人时计算。在对方领土上的吃子价值已通过围空分体现。

**提吃围困棋子时**：先解除围困（围困分-1），再获得歼灭分+2。防御分净变化+1。进攻方战损分照常-1。

#### 5.2 围困分

**围困定义**：被对方的**有效包围圈**包围 + 未做出两只真眼 + 圈内可合法落子的空点 < 4。

**围困分结算**（实时动态）：

| 事件 | 围困分变化 | 活子分变化 | 围空分变化 |
|---|---|---|---|
| **进入围困** | 防守方+1/子 | 进攻方-1/子 | 该棋子所在点开始计入防守方围空分 |
| **解除围困** | 防守方-1/子 | 进攻方+1/子 | 该棋子所在点不再计入防守方围空分 |

**围困分区域规则**：

| 包围圈位置 | 围困分 |
|---|---|
| 己方领土内 | +1/子 |
| 边境线上 | +1/子（可与围空分叠加） |
| 对方领土内 | 不计（被围空分覆盖） |

**围困解除方式**：
1. 做活（做出两只真眼）
2. 突破包围圈（包围圈被破坏）
3. 空点恢复到 ≥ 4
4. 被提吃（围困分-1，歼灭分+2，战损分-1）


### 第六章：围困判定

#### 6.1 判定时机

每当棋盘状态发生变化（落子、提吃）时，系统自动检查相关区域棋子是否满足围困条件。判定结果立即反映在分数上。

#### 6.2 基本原则

**棋子只有两种状态：活棋与围困。**

#### 6.3 活棋判定（满足任一即为活棋）

1. **有两个真眼**：无论是否被包围，无论空点多少。
2. **未被对方的有效包围圈包围**。
3. **被对方的有效包围圈包围，但圈内合法落子点 ≥ 4**。

#### 6.4 围困判定（同时满足以下三项）

1. **被对方的有效包围圈包围**。
2. **没有两个真眼**。
3. **圈内合法落子点 < 4**。

**有效包围圈**：由**活棋**围成的封闭几何边界。由围困棋子围成的包围圈无效。

#### 6.5 独立真眼的判定

一个眼位是独立真眼，当且仅当对方在该眼位落子属于自杀行为（禁入点）。

#### 6.6 可合法落子的空点

模拟落子判定：落子后有气，或虽无气但能立即提吃对方棋子，则该点可合法落子；否则为禁入点，不计入空点。

#### 6.7 判定规则速查

| 有两个真眼？ | 被有效包围？ | 空点 < 4？ | 结果 |
|---|---|---|---|
| 是 | — | — | **活棋** |
| 否 | 否 | — | **活棋** |
| 否 | 是 | 否 | **活棋** |
| 否 | 是 | 是 | **围困** |

#### 6.8 重要说明

- 不存在“死子”，只有活棋和围困。
- 不存在“双活”，双方互相包围时各自独立判定。
- 盘中屏幕提示：处于围困状态的棋子始终显示锁链图标。


### 第七章：战损分

| 触发 | 变化 |
|---|---|
| 在**任何位置**被对方实际提吃 | -1/子 |

**战损分与围困分**：棋子被提吃时，若当时处于围困状态，先执行围困解除（围困分-1），再执行战损分-1，最后执行歼灭分+2（若适用）。


### 第八章：劫争

#### 8.1 行棋规则

禁止全局同形再现。提劫后对方须找劫材，不得立即回提。

#### 8.2 盘中分数结算

每次提吃照常结算：己方领土/边境提吃 → 歼灭+2；被吃方 → 战损-1；同时检查围困状态是否变化。

#### 8.3 终局处理

终局时，劫争不再继续。以“谁在劫争中获益更大”为标准判定归属：
- 分别模拟双方获胜，计算各方分数净增加量（包括歼灭分、战损分、活子分、围空分、围困分变化）。
- 比较净增加量：大者得劫；相等则判给终局时实际控制劫子的一方。


### 第九章：布局阶段

#### 9.1 布局阶段定义

对局开始后，前2个回合（共4手）为**布局阶段**。

- 黑方第1手：必须落在**黑方领土**（第1-9行）。
- 白方第1手：必须落在**白方领土**（第11-19行）。
- 黑方第2手：必须落在**黑方领土**（第1-9行）。
- 白方第2手：必须落在**白方领土**（第11-19行）。

布局阶段结束后，从**第5手**（黑方）起正式开战，可落在棋盘任意合法交叉点。

#### 9.2 布局阶段规则

- **落子范围**：仅限己方领土，不可落在边境线或对方领土。
- **得分**：布局阶段落子在己方领土，不产生活子分、围空分、歼灭分或围困分。
- **吃子**：布局阶段双方棋子均在各自领土内，不可能发生提吃。
- **禁止虚手**：布局阶段必须落子，不可虚手。
- **兵力消耗**：布局阶段落子正常消耗兵力。
- **包围圈**：布局阶段在己方领土形成的包围圈，不产生围空分。

#### 9.3 布局阶段战略要点

| 落子位置 | 战略意图 |
|---|---|
| **靠近边境线** | 为第5手起抢线做准备 |
| **己方领土角部** | 构建后续包围圈的初始基础 |
| **中央附近** | 建立灵活的初始据点 |


### 第十章：行棋与终局

#### 10.1 行棋

- 黑先。
- **布局阶段**（前4手）：必须落在己方领土。
- **战斗阶段**（第5手起）：可落在棋盘任意合法交叉点。
- 交替落子，无气即提（结算歼灭/战损），禁自杀。
- **劫争**：禁止全局同形。
- 可随时虚手（布局阶段除外）。双方连续虚手→终局。对方落子后己方自动恢复落子权。
- **每手棋后自动检查**：包围圈形成/破坏 → 更新围空分；围困状态变化 → 更新围困分和活子分。

#### 10.2 强制终局

一方棋子用尽且双方连续虚手→终局。

#### 10.3 终局结算

1. 双方连续虚手。
2. 系统处理劫争（模拟判定）。
3. 对当前盘面进行最终死活判定，冻结所有动态分数。
4. 读取双方最终总分。**白方总分额外+0.5贴目**。
5. 比较：**黑方总分 vs 白方总分+0.5**。高者胜。分数相等则和棋。


## 第二部分：可选规则


### 可选规则：特种部队（隐秘行动）

#### 规则属性

- **类型**：可选附加规则。
- **适用模式**：自定义房间、全面战争模式。
- **默认状态**：关闭。

#### 技能详情

| 属性 | 设定 |
|---|---|
| 使用次数 | 每局2次，不可连续使用 |
| 持续时间 | 20回合（双方各走20手），到期自动现形 |
| 棋子消耗 | 不计入兵力上限 |

**宣告**：发动时，系统公屏提示，不提示具体位置。

**部署得分**：无即时得分。价值体现在终局奖励中。

**战损**：被提吃时战损为 **-6分**（对方歼灭分照常+2）。

**成功奖励**（三种互斥，终局时取最优一项）：

1. **参与围空**：该子在对方领土内为活棋且参与围空 → 该包围圈围空分**翻倍**。
2. **潜伏存活**：该子在对方领土内为活棋但未参与围空 → 该子计为 **+3占领分**（替代普通+1）。
3. **边境建功**：该子在边境线为活棋且参与包围 → 该包围圈产生的**防御分总额增加50%**（向上取整）。

**暴露条件**：对手落在该点或四邻格，或20回合到期。

**重叠处理**：对手落子与隐子重叠时，隐子现形，对手该落子随机弹至周围八格。

**终局处理**：所有未暴露的隐子现形，按正常规则结算，并判定是否触发成功奖励。

**版本改动记录（2026-08-14 围空分 BUG 修复）：**

- 回滚点：`git tag pre-cavity-territory`（指向修复前提交）
- 回滚命令：`git reset --hard pre-cavity-territory`（撤销以下全部代码改动）
- BUG：**同一种嵌套包围，出现不同的围空分**（同一结构放不同位置围空分不一致）
- 根因：`TerritoryDetector._collect_raw_enclosures` 只从「空连通块」检测包围圈。当包围圈内部被对方棋子填满（如黑实心墙的洞腔内是白方框）、且空区域直接边界为对方棋子时，该洞腔不构成任何检测到的围空圈 → 圈内**被围困的对方棋子不计入围空方围空分**（违反规则4.2「圈内对方围困棋子计入包围方围空分」），导致同结构围空分随位置出现 0/2/2 等不一致且偏小的分数
- 修复（`TerritoryDetector.gd`）：
  1. 新增**洞腔围空检测（Pass B）**：`_compute_outside` 重构为 `_compute_wall_components`（一次 BFS 同时得到「外部」与全部「洞腔」）；对每色墙的每个洞腔，若其空点未被 Pass A 同色圈完全覆盖则补建围空圈，使圈内对方围困棋子得以计分；空点归属仍由 Pass A（最内层直接边界归属）决定，嵌套去重保证不重复
  2. 排序改为**区域升序 + seq 稳定序**（内层小圈先处理），保证规则4.3「内层活棋归内方」语义（外层洞腔圈不抢占内圈空点）
  3. `stones_inside` 语义与文档一致：「纯几何候选，不做死活筛选，计分时由 ScoreCalculator 判定围困」——两真眼活棋几何上在洞腔内但计分时被排除（规则4.2 对方活棋不计入）
- 得分变化（同结构黑实心墙围白方框）：黑境 0、边境 12（中心2 + 攻击区5子×2）、白境 18（8子×2+中心2）；同行不同列完全一致
- 测试：`test_territory_siege_edge.gd` C4/C7/C8/C9 期望更新（2→12/18）；`test_territory.gd` 用例7 改为计分层排除活棋断言；主测试 953 通过 + SGF 审计 40400 项 0 失败

**版本改动记录（2026-08-14 混合边界口袋归属修复）：**

- 回滚点：`git tag pre-min-cavity`（指向修复前提交，含上一笔洞腔围空修复）
- BUG：**同样的镜像结构，围空分不对称**（真实对局左上/左下互为镜像，左上围空少算 1 点）
- 根因：`TerritoryDetector` Pass A 对混合边界空区域（如 (3,3) 邻接黑2+白2 子）取 `border_colors` 遍历中**第一个**能封闭它的颜色。左上角白 L 形墙是内层包围圈、黑外墙是外层，但边界颜色遍历先扫到黑 → 判给外层黑，违反规则4.3「内层由活棋围成 → 区域归内层方」。左下镜像恰好内层也是黑且先被扫到而碰巧正确 → 呈现不对称
- 修复：多色均可封闭该空区域时，选**包含它的最小洞腔**（= 最内层包围圈）。`_collect_raw_enclosures` 预建每色 `idx→洞腔大小` 索引（`cav_idx`），Pass A 在所有可封闭色中取洞腔最小者
- 得分变化（真实对局第46手）：黑 37 不变；白 35→37（(3,3) 口袋由黑转白 +2）。贴目0.5后 黑36.5 : 白37 → 白胜
- 测试：新增 C10 镜像回归（左上白内层围空28 = 右下黑内层围空28，总分对称）；主测试 956 通过 + SGF 审计 40400 项 0 失败
